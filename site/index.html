MAGIC

A language for pictures, terminals, and games.

Alpha. Early work.

Start learning Try a program

MAGIC mixes Lua and BASIC, and it compiles to JavaScript. @canvas loads a module. end closes a block. A script can be a first program or a game you pack into its own window.

Canvas

Sprites, a bitmap, and a frame loop. The picture half of the 2D engine.

Terminal

A cell grid for text games, panels, and the UI kit.

Sound, hex, games

Notes, hex boards, clocks, scenes, and scores. They ship with the language.

A program

@canvas
@games

let engine = new Engine({ width: 320, height: 180 })
let spark = engine.sprite("✦", 40, 90, 28)
engine.motion(spark, 4, 0)

for i = 1 to 10
  engine.update()
end

print spark.x
print clamp(spark.x, 0, 200)

magic run runs it. magic app turns it into an Electron project. npm run pack in that project builds a standalone app.

Alpha. MAGIC is early work, and it can still change. The definition is LANGUAGE.md.
