Language

LANGUAGE.md is the definition: every form, every rule, every built-in word. A highlighter or another compiler should also read lang/magic.language.json, the EBNF, and the TextMate grammar.

The shape

  • A newline ends a statement. end closes a block.
  • Keywords ignore case. Names keep their case.
  • = assigns. == compares.
  • nil, false, 0, and "" are false.
  • Indexes start at 0. for i = 1 to 3 visits both ends.
  • fn declares a function. class declares a class. fn new is the constructor.
  • @strict checks the types you wrote with as.
  • @canvas and the other module names load a library.
class Counter
  n = 0
  fn new(start)
    self.n = start
  end
  fn bump()
    self.n = self.n + 1
    return self.n
  end
end

print Counter(1).bump()
