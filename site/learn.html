Learn

The short course is LEARN.md. This page is the same path, with the first programs you can paste into the playground.

Hello

fn greet(name)
  return "Hello, " .. name
end

print greet("MAGIC")

.. joins text. print writes a line. A newline ends a statement.

A choice and a loop

for i = 1 to 3
  if i == 2 then
    print "two"
  else
    print i
  end
end

= stores a value. == compares. end closes the block. for i = 1 to 3 visits 1, 2, and 3.

A module

@canvas loads the picture module. The names Engine, Canvas, and Utilities are then yours.

@canvas

let engine = new Engine({ width: 320, height: 180 })
let spark = engine.sprite("✦", 160, 90, 36)
print type(engine)
print spark.emoji
