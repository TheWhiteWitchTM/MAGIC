Modules

@name loads a module for the whole file. import loads the same module when you want to choose the names. The full export lists are in MODULES.md.

ModuleYou get
@canvasA bitmap, sprites, and the frame loop.
@terminalA cell grid. Use @terminal as term beside canvas, because both export Utilities.
@2dCanvas and terminal together.
@3dA 3D scene. Load it as @3d as world when the file also uses canvas.
@uiWindows, buttons, and menus on a terminal.
@soundTones, named notes, and noise.
@hexNeighbors, distance, rings, and pixel layout for a hex board.
@gamesLoops, keys, scenes, scores, and small arithmetic.

Hex

@hex

let here = hex(0, 0)
print distance(here, hex(2, -1))
print len(neighbors(here))

That prints 2, then 6. Direction 0 is east.
