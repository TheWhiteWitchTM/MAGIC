Tools

CommandWhat it does
magic run file.magicCompile and run.
magic compile file.magic -o game.jsWrite one JavaScript module.
magic app file.magic -o build/gameWrite an Electron project.
magic pack file.magic --buildWrite that project and build a standalone app.
magic serveOpen this site.
msx file.magicRun MAGIC the way tsx runs TypeScript.
js2magic file.tsDraft MAGIC from JavaScript or TypeScript.

Inside an app folder, npm start opens the window and npm run pack writes a standalone build under dist/. The steps are in tools/electron.md.

For editors and compilers

  • magic.language.json — keywords, builtins, modules, exports
  • magic.ebnf — the grammar
  • magic.tmLanguage.json — TextMate
  • magic.vim — Vim
  • editors/vscode — a small extension

INTERFACES.md is the compiler, the runtime, and the packager. ARCHITECTURE.md is how the pieces sit.
